本次验收覆盖：

- 两机构及同机构岗位、归属、列表/详情/关联项/导出/报表/附件的边界；教师兼财务不会获得其他班级教学详情。
- 新报名无需课程包；定金不转化，缴清确认后开通课时；重复签到和同学员多笔报名不重复扣课或统计人次。
- 退款原因、课时快照、退读关系与剩余课时留痕；其他项目仍在读时不误计机构流失。
- 同批次转化回补、月度分母、恰好30%报警、无分母与历史待校准、取消课次、调班和原任课教师 KPI。
- Excel 扫描核对、全部列编辑、自定义列、稳定编号、重复确认、版本冲突；纸表报名/退费标记不自动记账。
- 浏览器多人页面正常连接下5秒内更新；机构切换和岗位入口受限。
- 表单字段权限与加密，版本固定，条件预演，会签/任一通过，退回修订，审批人停用重新分配，附件按现有权限读取。
- 财务默认直接登记；启用模板后直接请求不能绕过；并发实际发生确认只生成一笔费用，并发收款与签到不重复。
- 咨询默认暂停、自媒体内容计划独立保留、数字人未接通时不创建直播。
- 企微协议通过模拟超时、去重、配置撤销与未知结果核实验证；**没有发送真实企微群消息**。
