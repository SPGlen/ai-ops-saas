# 知营 · 企业演示使用说明

这份演示以现有产品为基础，使用独立数据库和虚构业务资料。展示真实的权限、表单保存、课时与财务计算，不把预置案例当作真实模型生成、真实收款或真实平台发布。

## 现在怎样打开

在项目根目录双击 `启动企业演示.cmd`，浏览器进入 `http://127.0.0.1:8188/`。登录页可直接选择机构负责人、招生、授课、教务、财务、内容运营或授课兼财务。登录和岗位权限仍由原认证服务校验。

如果页面仍停留在旧预览，请刷新页面。原开发数据库 `.local/ops.db` 保留，演示使用 `.local/showcase/runs/` 下的独立数据库。没有修改原数据库的收支、课时和历史报表。

- `启动企业演示.cmd`：打开或重启本机演示；当天保留操作结果。
- `重置企业演示.cmd`：创建新的演示数据库和素材，恢复预置案例；原演示运行目录保留。
- `停止企业演示.cmd`：只停止经核实属于本项目的本机演示进程。
- `开启临时外网演示.cmd`：创建带访问码、默认8小时到期的临时 HTTPS 地址，使用另一套独立演示数据。
- `关闭临时外网演示.cmd`：停止本项目的临时隧道和独立外部演示服务。

后台进程隐藏运行，关闭启动命令窗口不会关闭服务。结束演示时使用停止或关闭入口。电脑必须保持开机、联网，演示前请关闭自动休眠。

## 给外部企业打开

临时外部入口通过官方 cloudflared 固定版本建立，只转发到本机独立演示端口8191。首次启动自动下载官方工具并核对 SHA256，不需要购买域名或部署云服务器。地址重建后会变化，免费临时隧道不保证访问稳定性。

访问者直接打开临时域名，在网页中输入演示访问码，无需用户名，也无需手动添加 `#demo`。访问码和当次网址保存在本机 `.local/showcase-shared/外部演示访问说明.txt`。验证后选择业务岗位，同一浏览器刷新会保留访问状态（最长8小时，链接本身到期后仍会关闭）。访问码不是平台或供应商密钥，不要在链接参数中携带它；仅发给获准体验的人。

需要其他有效时长时使用 `scripts/share-showcase.ps1 -Hours 24`，允许1至72小时。到期后 HTTP 返回410，需要重新开启；本机服务和外网演示互不覆盖。若本机外网探测失败但隧道仍在线，使用手机移动网络确认，不把“隧道启动”当作外部验收通过。

演示使用5秒轮询刷新，适配不支持SSE的免费临时隧道。正式产品仍使用SSE和原有断线回补。临时入口仅用于展示，不是正式云部署或生产交付。

## 现场8分钟讲解路线

1. **30秒：负责人总览。** 强调服务面向机构创业者，一人可兼多岗，也能组织团队协作。展示当前岗位、经营数字、工作入口。
2. **1分钟：招生线索。** 打开招生表、负责人和跟进阶段；可上传资料包内的 `演示招生表.xlsx`，核对后确认导入。演示Excel实际解析；图片、PDF真实OCR本环境关闭，会给出明确提示。
3. **1分钟：班级与学员。** 打开一个班级，再打开学员详情，查看家长、课时和出勤。教师仅可见任教范围。
4. **1分30秒：财务与票据。** 点击实收或费用指标，进入明细；选“教室场地费”的“查看票据与详情”，展示带演示水印的原件。再打开一笔退款，查看购买、已上、未上课时和退读原因。
5. **1分钟：周报、月报及异常。** 切换月报，查看同批线索转化、流失率、出勤、课返KPI、家长反馈和财务汇总。青禾案例预置30%流失场景，用来讲解预警。站内数据真实计算，企微推送没有发送。
6. **1分钟：自媒体矩阵。** 查看两个品牌、六个账号、分组和每周二五的计划。账号均显示未连接，计划关闭。返回演示总览，展示图文与15秒无声程序合成视频。
7. **1分钟：授权与岗位切换。** 打开成员与授权，再切换“授课”。观察财务、内容入口消失，学员范围收缩。展示“授课兼财务”，说明权限按业务操作合并。
8. **30秒：交付边界。** 说明可以配置机构流程并部署云端。DeepSeek、真实媒体供应商、真实平台发布、真实OCR及正式云运行分别安排联调，不承诺现场已经完成。

## 已准备的数据

- 青禾：30名虚构学员、60条招生线索、3个班级、历史报名、签到、请假、9笔退读退款、费用原件、家长反馈、周报月报和流失预警。
- 星光：12名虚构学员和独立的业务数据，用于对照机构隔离。
- 青禾矩阵：2个品牌、6个示例账号、2个关闭的周期计划、图文成品及程序视频。没有虚构作品编号、平台指标、已发布状态或真实模型消费。
- 演示统计会随现场操作更新；重置可恢复基线。报表按实际运行日生成，预置历史仅属于演示数据。

## 展示能力和待接入能力

可以现场操作：登录切换、机构岗位授权、招生录入与Excel核对、报名登记、班级档案、课时与签到、课返完成KPI、票据查看、收退款台账、周月报、站内异常、矩阵品牌分组及计划编辑。

外部操作关闭：真实AI调用、媒体供应商任务、账号登录与发布、平台指标采集、邮件、企微通知和凭证录入。扫描图片/PDF的OCR需要单独配置与验收。DeepSeek适配尚未完成；付费数字人直播仅为申请入口。

软件中的已生成摘要由确定性统计规则汇总；本演示没有把AI预写文本当作现场模型输出。15秒视频是真实FFmpeg合成的无声样例，不代表45—90秒AIGC工作流已经完成供应商验收。

## 演示前与备用资料

提前在本机完整走一次路线，测试投屏分辨率。演示当天点击“重置企业演示”，再选择负责人。若需要外部链接，当天重新生成并使用手机移动网络打开确认。

资料包在 `.local/delivery/showcase/`：包含离线截图导览、录屏、招生示例表及本说明。网络异常时可以直接播放本地MP4或打开离线导览，仍能展示结果。离线导览是截图资料，不执行后台业务。

本机原始数据和恢复说明在 `.local/backups/showcase-20261023-151755/`。备份包含本地资料与历史业务，不属于给企业的演示资料包。

## 技术与验证

专用开关 `OPS_DEMO_MODE=true`、`OPS_TASK_MODE=demo`。启动检查拒绝把普通机构数据库作为演示数据库，拒绝携带真实供应商配置。后台调度器不启动；仅允许Excel导入的本地解析任务。HTTP写接口白名单只控制演示边界，原有身份、CSRF、机构和岗位校验继续执行。

临时入口使用访问码、HTTPS安全Cookie及到期关闭；演示数据、登录态与原项目分开。原生产环境默认不开启演示开关。

验证结果见 `showcase-api-tests.xml`、`showcase-regression-tests.xml`、`showcase-browser-tests.json`、`showcase-external-test.json` 和 `showcase-acceptance.json`。云端正式验收仍以 `release-gates.json` 为准。

官方临时隧道说明：https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/
固定工具版本和哈希：`demo-tools-lock.json`。
