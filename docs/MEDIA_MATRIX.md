# 自媒体矩阵运营 0.4 使用与交付说明

本版将品牌、矩阵账号、选题、AI分镜、媒体、盲评、发布、T+3回收与复盘接入原 SaaS。入口为「自媒体矩阵」，浏览器路径 `/#matrix`。服务端调度无需持续打开 ChatGPT。

## 账号接入前先区分环境

完整图文操作见[网页版手册](USER_MANUAL.html)第8至13页。企业演示使用独立虚构数据，扫码登录、真实模型、发布和回复都会返回演示限制；添加账号仅是建档。真实账号接入需要另一套测试数据库、存储、密钥和发布节点，不改动企业演示。

部署人员先配置受控发布网关的地址和认证，再由负责人逐个账号扫码、回读真实身份。核验能力按钮不会实际发布作品；发布能力和指标能力要通过对应真实结果分别确认。视频号稳定账号ID回读仍待适配，当前不能据扫码状态启用无人值守。评论和私信自动回复继续暂停。

## 负责人首次配置

1. 在「品牌与分组」创建品牌，选择已审核的机构知识库和已授权图片/视频。不会自动读取学生档案、家长反馈或私人订单。不同品牌分别选择资料、素材和评分规则。
2. 添加平台账号，选择品牌、账号定位、内容形式、行动引导语和账号月预算。同平台可添加多个账号，账号可加入多个同品牌分组。
3. 在「预算与机构总开关」设置机构月预算。机构、账号月预算及计划日预算、单次预算均生效；为零时不能产生新模型调用。平台额度与自带Key分别使用，不会自动切换。
4. 每个账号分别扫码，检查真实身份；点击「核验能力」检查可验证的读取能力。只有连接器明确返回本人账号身份，才可用于无人值守发布。未取到可靠ID时显示待核验。
5. 创建运营计划，选择明确账号/分组、内容方向、数据源、时间和审核策略。默认中国时区周二、周五18:00，45—90秒视频，逐条审核，自动执行关闭。
6. 负责人保存的版本可直接试运行；内容运营保存的版本须先由负责人授权预算。试运行只自动生成成品和独立盲评，不自动发布。
7. 首次真实发布在「发布与复盘」手动进行；结果未知先核实。核实成功会记录作品编号、链接和已验证发布能力。当前计划版本试运行通过、账号身份及能力验证通过后，负责人再启用定时计划。

内容运营岗位可操作本机构全部账号，不设置逐账号员工授权；账号凭证、绑定、预算、机构开关及定时发布启用由负责人控制。财务、教师、招生等其他岗位不会因矩阵接入获得内容权限。

## 日常运营

- 母题矩阵：共享选题，分别创作标题、正文、封面和分镜。共享选题费用单列一次，其他费用按账号任务记录。
- 独立运营：各账号依据自身定位分别选择选题与创作。账号当前归属、计划版本、品牌资料、事实版本和目标账号在运行创建时固定。
- 分组重叠时去重。分组变化只影响新运行；不会将已创建任务改投其他账号。品牌、计划、授权、事实或身份改变时，执行前重新校验。
- 「任务与复盘」查看步骤、制作方式及理由、固定成品、费用和错误；逐条审核模式通过后才排期。
- 各任务提供专属预约链接 `?source=matrix:<task_id>`。通过该入口创建的线索按账号汇总，正式报名按现有 `won_at` 业务状态计算。未关联来源不推测归因，不跨平台自动合并家长身份。
- 日历的「计划时段」为预排；生成、审核或授权异常可能影响实际发布时间。定时调度会处理15分钟内的到期时段，较早错过的时段不会集中补发。
- T+3通过平台采集本人作品指标；不支持或失败时标记缺失，保留手工补录。按平台分别展示，不能把缺失当零。
- 机构、分组与账号过滤可查看发布量、成本和逐作品实绩；周报月报按原岗位权限加入自媒体摘要。

## 视频与评分

AI导演输出程序合成、AIGC或混合分镜，只选择计划允许的方式。AIGC片段单独保存供应商任务ID并查询，最终由FFmpeg完成分镜合成、配音、字幕、封面和品牌片尾。实际音轨与2秒片尾总长度必须满足计划范围；不符合时进入待处理，不能伪装为合格成品。

字幕按每段实际音轨时长和配音字符比例分配，当前没有接入语音强制对齐。程序合成为确定性卡片/图文片段，不能替代真实课堂证据。

评分仅接收最终成品、对应脚本及独立评分规则，不读取该作品发布实绩。预测不可覆盖，修改内容产生新版本。品牌图文、视频规则独立，初始状态标记未校准。规则升级须完成该品牌完整样本池重算及不同模型复核，由负责人启用；启用后相关自动计划需重新确认。

## 暂停、异常与恢复

- 暂停账号、计划或运行，会停止后续新调用与未提交发布。已提交的付费任务继续查询、存储及结算。
- 发布结果未知保持待核实，不重发；同一账号有执行中或未知发布时，其他发布排队等待。成功作品必须有可核实编号和链接。
- 供应商明确拒绝且原调用零用量结算后，可在账号步骤中「重试明确失败的调用」。新尝试重新预占预算，重试请求幂等，其他账号不重做。
- 超时、未知结果不能通过重试创建付费任务。已有供应商ID、结果地址或原始素材时，用「继续回收已有结果」。共享选题失败需重建运行；预算不足或环境缺失修复后可恢复运行。
- 角色撤销、员工停用、负责人授权失效、使用期到期均阻止新操作。已有供应商付费结果的回收不受暂停影响。
- 企业微信管理群只推送任务与经营摘要，不发送学生或家长明细。网页/微信AI咨询及评论、私信自动回复仍暂停。

## 部署与升级

- 应用镜像及源码版本：`0.4.0-rc1`；生产迁移：`alembic upgrade head`，新增修订 `0005_media_matrix`。完整离线SQL为 `migration-upgrade-0005.sql`，迁移凭证和运行凭证继续分离。
- 升级前停旧Worker并备份数据库、私有对象存储和发布节点加密状态，按原 `DEPLOYMENT.md` 执行。旧按平台路由的计划迁移为待确认草稿；历史内容、预测、用量和明确绑定账号的发布任务保留。旧计划未提交的模型调用停止，已提交任务只回收已有结果。
- 账号套餐默认9个，平台管理员在「平台管理 → 机构权益」调整。负责人控制月预算；平台管理员调整数量不会自动提高预算。
- `OPS_MATRIX_SOURCE_HOSTS`：平台维护的RSS/Atom HTTPS域名白名单，逗号分隔；空值禁用外部Feed，仍可使用常青选题或已验证的小红书搜索。Feed最大2MB，不跟随跳转，禁止私网地址，使用安全XML解析器。
- `OPS_MATRIX_MAX_RUNNING` 默认2，控制每机构同时推进的运行数；宿主并发由Celery和资源限制控制。
- 浏览器节点 `PUB_BROWSER_MAX_CONTEXTS`、`PUB_XHS_MAX_ACTIVE` 默认2；空闲上下文或MCP进程加密保存账号状态后释放。每账号独立登录状态与任务锁。
- 模型、FFmpeg、中文字体、私有S3、邮件、正式域名和浏览器节点仍按部署手册配置。代码内不保存原个人项目的账号凭证或历史素材。
- 财务展示的模型费用依配置单价和实际用量计算，不能视为阿里云账单核对结果。单价未配置时不开放对应调用。
- 回滚使用匹配的源码、镜像和已验证备份；不执行删除新表的破坏性降级。原始台账与预测仍受不可修改约束。

## 验收证据与待联调

- `matrix-api-tests.xml`：完整业务及矩阵自动化测试；模型和发布使用模拟传输。
- `matrix-migration-test.json`：PGlite PostgreSQL兼容环境，48张机构表RLS、历史计划迁移、跨机构外键及版本不可修改；不等同于原生PostgreSQL验收。
- `matrix-media-test.json`：真实FFmpeg，三种制作方式，使用合成静音和色块视频作为输入；不等同于真实TTS或万相视频。
- `e2e-report.json`：隔离数据库的浏览器验收；`screenshots/matrix-accounts.png`为矩阵界面截图。
- `matrix-acceptance.json`：汇总本次实际测试与待验收项。

真实百炼文字/图像/TTS/视频、三个平台授权账号、可靠账号身份、真实作品编号与链接、T+3指标、企微推送、原生PostgreSQL及Docker运行、阿里云部署均单独记录。缺少环境或账号时维持「待验收」，不把模拟结果当真实联调。


当前身份接入边界：小红书实现本人资料ID回读；抖音实现创作者页面显式本人主页链接识别，仍待真实页面验证；视频号的稳定账号ID回读尚待真实账号适配。后两者未通过时不会开启无人值守发布，扫码成功不会被当作身份核验成功。手动首次发布及回填也必须单独验收。


运行中的成品版本不会随内容工作室的编辑而改变。编辑会产生新版本，原预测保留；新版本须重新盲评后单独排期，或创建新的计划运行。运行详情同时展示步骤费用、预占金额及单列一次的共享选题费用。
