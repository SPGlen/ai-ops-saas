# 0.3.1 多岗授权与经营报告

本系统面向教育机构创业者及其团队。“一人公司”表示一人可以承担多项职责；员工人数不受此定位限制。所有功能授权由机构负责人管理。

## 成员与授权

负责人进入侧栏“成员与授权”，查看员工、状态、已授功能及权限版本，点击“调整授权”多选职责；保存后，后续接口与后台任务重新校验。停用成员暂停全部访问。最后一名有效负责人不能被停用或撤销。

| 授权 | 范围 |
|---|---|
| 招生 | 本人线索、试听及订单，不能登记收退款 |
| 授课 | 本人任教班级和学员、签到、课返KPI、反馈登记 |
| 排班 | 本机构班级查看和排课维护，不包含学员联系方式、签到及财务 |
| 教务 | 本机构学员、分班、请假补课、课时、课返及家庭反馈；排课修改另授排班 |
| 整体营收查看 | 实收、退款、净收汇总和趋势；不含订单、费用、票据及学员资料 |
| 财务 | 收退款、费用、票据、渠道及结算；不含教学内容和家庭反馈 |
| 内容运营 | 内容生产、自媒体发布及复盘 |
| 负责人 | 本机构全部业务、配置及员工授权 |

兼任按具体操作合并。例如“授课+整体营收查看”可以看机构净收，学生和家庭反馈仍限本人任教范围。平台管理员仍需机构成员身份访问业务。

修改采用权限版本检查，并发修改冲突要求重新读取；权限刷新最长约5秒，后端每次请求立即校验。授权目录由服务端提供，前端隐藏入口不替代接口检查。成员邀请支持以上组合。

## 财务与票据

“营收总览”只显示已登记实收、退款及净收的现金口径汇总和趋势，不等同于按课时确认的收入或利润。财务人员进入“财务台账”，点击图表筛选对应流水，再点订单或“查看票据与详情”。弹窗显示金额、关联订单收款图表、退款课时快照、票据原件、OCR核对结果、审批和操作历史。

票据可关联多张图片/PDF；图片可预览，点击打开受权限校验的原件。OCR结果仍须财务核对。这里登记实际财务结果，不执行银行退款。

## 学员与家长反馈

教务页切换“学员家长反馈”，或从学员详情进入。记录关联学员和班级、来源、类别、可选1至5分评分、发生时间及实际反馈；处理完成必须填写结果。

教师可查看本人班级反馈，登记和修改本人录入、尚未处理的反馈；处理结果由教务或负责人确认。财务、招生、自媒体和营收查看授权不包含家庭反馈。反馈正文及处理结果加密保存。

本功能记录家庭的实际意见，与“老师是否完成课返”的KPI分开。空反馈或未评分不会被推断为满意。

## 自动周报与月报

默认中国时区：每周一09:00生成上周周报，每月1日09:00生成上月月报。负责人在“经营规则与提醒”修改时间并配置管理群机器人；本地预览启动时运行调度，生产须同时启动Worker和Beat。

报告包含：招生和转化、在读与退读、出勤与课返KPI、实收退款净收及费用、家庭反馈数量/类别/均分/待处理/低评分，并生成可追溯的文字经营摘要。当前摘要由确定性规则生成，不把模型推测当成经营事实。

负责人在“经营周报/月报”的“自动生成与历史报表”打开已保存版本。历史版本不可覆盖，补录和更正生成新版本。普通员工读取按当前授权范围计算的报告，不能获取负责人完整快照。管理群仅发送经营摘要和查看链接，不发送姓名、联系方式或反馈原文。

## 兼容与网站入口

SQLite开发环境在初始化时执行一次兼容升级；生产使用Alembic `0004_capabilities`。既有教务员工原本可排课，升级时追加“排班”保留原权限；此后负责人可单独撤销，重启不会重新授予。新机构新授权按独立职责设置。历史订单、现金/课时流水和审计不修改。

主站本轮未修改。未来统一登录需复用现有主站身份、机构和正式管理入口，当前运营工程保留独立部署；不复制网站密码、积分、激活码或课程进度数据。

## 验证边界

本轮自动化结果见 `management-acceptance.json`。浏览器测试使用隔离的合成数据；票据测试验证附件关联、预览和下载，不代表真实发票OCR准确率。PostgreSQL迁移在PGlite中验证，原生PostgreSQL与云端部署、真实企微群发送和外部账号联调仍需分别验收。

升级前备份数据库、私有附件和加密主密钥。0.3.0之前的自动化证据保留为历史记录，不能替代本版验收。

本版复验命令（项目根目录，生产数据库不用于测试）：

```powershell
.venv\Scripts\python.exe -m pytest backend\tests -q --junitxml=docs/management-full-api-tests.xml
.\scripts\test-browser.ps1
node frontend\test-management-migration.mjs
.venv\Scripts\python.exe scripts\test-management-restore.py --backup <本轮备份目录>
.venv\Scripts\python.exe scripts\release-management.py
.venv\Scripts\python.exe scripts\package.py
```

浏览器新增授权用例使用独立的本地测试客户端地址，避免各测试文件累积触发同一IP的登录限流；生产限流规则未放宽。
