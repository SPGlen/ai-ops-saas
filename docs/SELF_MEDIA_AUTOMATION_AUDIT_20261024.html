  • 品牌、分组、账号明确路由与运行快照

在“自媒体矩阵 → 品牌与分组 / 自动运营计划”中，可设置品牌受众、定位、已审核资料、目标账号、来源、星期与时刻、预算、制作方式和审核策略。启用需要负责人授权及当前计划版本的成品试运行。

真实账号联调的启用条件

  1. 在独立测试环境使用独立数据库、对象存储与发布节点，避免重用企业演示运行目录。
  2. 逐账号扫码并回读真实身份，核对已授权能力；小红书私信保持未接通，抖音互动按官方授权验证。
  3. 配置机构、账号及计划预算；真实模型试运行会产生模型费用，本轮模拟预演没有调用真实模型。
  4. 固定品牌知识与计划版本，完成成品、盲评、审核，再验证发布作品编号、链接及可见状态；结果未知时先核实。
  5. 自动回复需先从暂停的咨询模块独立出来，先验草稿、去重、接管与发送结果回读，再按账号启用。
